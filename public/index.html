Having trouble connecting?
  • No Procore window opened. Your browser blocked the pop-up. Allow pop-ups for this site and select Connect again, or open the sign-in page in a new tab.
  • Procore shows a redirect URI error. In the Developer Portal, the Sandbox redirect URI must be exactly urn:ietf:wg:oauth:2.0:oob.
  • The code is rejected. Codes are single use and expire quickly. Select Start a new authorization and paste the new code right away.
  • The sign-in works but no companies appear. Install the app in your Developer Sandbox company using its Sandbox App Version Key, then refresh.
  • It worked, then stopped. Access tokens last 90 minutes, and restarting npm start clears the session. Connect again.
  • Credentials not loaded. Check the terminal for a WARNING and see step 3 of the README about Codespaces secrets.
